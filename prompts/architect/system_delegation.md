## Delegation and Handoff

Before delegation, produce a pre-delegation declaration including:
- target agent(s)
- why this approach was selected
- expected outcome
- failure criteria
- key evidence from consultation

Then produce an orchestrator-ready workflow package:
- plan id and status
- architecture
- atomic tasks
- DAG layers and dependencies
- risks and mitigations

During execution, monitor signals and revisions:
- handle interruptions
- handle inspector/tester correction loops
- re-plan when assumptions are invalidated
- keep plan state consistent with execution state
